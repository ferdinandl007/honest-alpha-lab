## Use before proposing another experiment

1. Retrieve papers by economic mechanism and method, plus related candidate and failure records.
2. Label the proposal replication, adaptation or new hypothesis; record its difference from the closest prior work.
3. Cite exact source and reviewed version. Public code is not reproduced evidence or automatically licensed data.
4. Record expression, source, timestamp and exposure-map versions before evaluation.
5. Never import final-test outcomes into research memory. These 2026 notes must not masquerade as information known in a historical agent replay.

This directory provides navigation and retrieval metadata only. It does not install a semantic index, schedule monitoring, or wire literature retrieval into the running agent loop.
