# Generating Synergistic Formulaic Alpha Collections via Reinforcement Learning

Source: [primary source](https://arxiv.org/abs/2306.12964) · [author repository](https://github.com/ICT-FinD-Lab/alphagen).

## Evidence reviewed

AlphaGen optimizes a collection of complementary formulas rather than treating each factor as an independent winner. The author repository includes Qlib integration and alternative search implementations.

## Application to Honest Alpha Lab — our recommendation

Use marginal contribution to a fixed existing library as a research objective. Reuse the classic genetic-programming baseline where licensing and interfaces permit.

## Limits and remaining checks

The reinforcement-learning generator is outside phase 1. Repository availability is not proof of performance on our US-equity universe; neither the paper result nor code has been reproduced here.
